# SKILL: David Rudnick "Making Time" Aesthetic Generator Rules

## 1. Composition & Layout Framework
- Outer Canvas: Solid deep black (`#000000`).
- Canvas Subdivision: 5-column asymmetric grid.
  - Column 1 (Left 20%): Vertical 90-degree rotated macro-display text running bottom-to-top.
  - Columns 2–3 (Center 40%): Interlocking geometric container paths enclosing central 3D/pixel graphic.
  - Columns 4–5 (Right 40%): Curved negative space cutouts housing metadata text blocks.
- Frame Margin: 16px solid black outer border with a subtle top/bottom inner line.

## 2. Color Palette System
- Canvas Base: `#000000` (Black)
- Container Fill: `#E0DEEA` (Pale Lavender Grey)
- Focal Graphic Accents:
  - Magenta/Pink: `#E28DBA`
  - Deep Green: `#237144`
  - Neon Cyan: `#00E5FF`
- Text Inks: `#FFFFFF` (White on black) and `#000000` (Black on lavender)

## 3. Typographic Scale & Rules
- Scale Ratio: Extreme contrast (1:8 ratio between body copy and left display rail).
- Display Class (Left Rail): Heavy modular/blackletter display font, tracking tight, 90° rotation counter-clockwise.
- Lineup & Meta Class (Right Side): High-contrast Classical Serif (Italic).
  - Primary Lineup (H1): 24pt, Italic, Right-aligned.
  - Secondary Lineup (H2): 16pt, Italic, Right-aligned.
  - Venue / Details (Body): 14pt, Italic, Right-aligned.
- Stamp Class (Top Center): Monogram logo (`M/T` intersecting glyph) above small italic serif description.
- Technical Label Class (Bottom): Compressed Mono, 10pt, All-Caps.

## 4. Graphical Elements & Rules
- Central Feature: Pixelated or voxel-rendered organic object (e.g., rose, flower) mounted on a thin geometric multi-segment stem.
- Container Lines: Continuous variable-stroke curves creating enclosed "island" masks.
